THE OBSERVATORY

What is taken, and what turns.

Instruments, not opinions. Every reading below carries the source it came from and the date it was fetched. Nothing is estimated: where a source could not be reached, the instrument says so instead of showing an old number as if it were current. And every instrument has two hands — what is being taken, and the turning away from it — because an instrument that only counts the wound is an accusation with no way out.
